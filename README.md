# Cidade-Portfólio — Higor Dornelas

Cidade arquitetônica interativa em SVG/React com nove projetos e iluminação **dia, entardecer e noite**. Edificações e espaços urbanos são elementos vetoriais interativos; a Agadê é o marco central, a Lumear está em obras e a Pastelaria é um lote futuro.

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

## Publicação

A ação `.github/workflows/deploy.yml` executa o build e publica o diretório `dist` no **GitHub Pages**. Em **Settings → Pages → Build and deployment**, selecione **GitHub Actions** como fonte. Após a primeira execução bem-sucedida, o endereço previsto é `https://higordrnls.github.io/portfolio-cidade/`.

## Percurso

O projeto não depende de uma imagem PNG ou SVG estática como mapa de fundo. O build é verificado automaticamente no GitHub Actions.
