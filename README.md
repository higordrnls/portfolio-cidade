# Cidade-Portfólio — Higor Dornelas

Cidade vetorial interativa, com nove projetos, edificações em SVG, praça central, iluminação diurna, entardecer e noturna. Não usa imagem de fundo. Agadê é o edifício central, Lumear está em construção e Pastelaria é um lote reservado.

## Rodar

```bash
npm install
npm run dev
npm run build
```
